# B. 大文件（25MB - 2GB）

## ⭐ 链接
```
https://github.com/ark-notes/ark-uploads/releases/tag/bigfiles
```

## 步骤（详细）

### 第 1 步：打开链接
**你会看到一个 Release 页面**，标题是：
```
📤 大文件上传（点 Edit 传附件）
```

### 第 2 步：找「Edit」按钮
**位置：**
- **电脑** → 页面**右上角**，有个 **✏️ 铅笔图标** 或 **"Edit release"**
- **手机** → **横屏**或**往下滚**，右上角有 **✏️**

### 第 3 步：滚到最底部
**在编辑页面，一直往下滚，找到这一段：**
```
┌──────────────────────────────────────┐
│  Attach binaries by dropping them    │
│  here or selecting them.             │
│                    [selecting them]  │
└──────────────────────────────────────┘
```

### 第 4 步：选文件
**点「selecting them」→ 选你的录屏**

### 第 5 步：等上传
**大文件慢，别关页面**（用 WiFi）

### 第 6 步：保存
**滚到最底部 → 点绿色 「Update release」**

✅ **完成**

## 如果找不到 Edit 按钮
- **用电脑**（浏览器按钮更明显）
- **或横屏**看
- **或告诉我「找不到」→ 我截图标位置**

# C. 超大文件（Mega · 2GB - 20GB）

## 为什么用 Mega
- **20GB 免费**（比 GitHub 大 10 倍）
- **手机 App 好用**
- **我能读**（已装 megatools）

## 第 1 步：装 Mega App
- **iPhone**：App Store 搜 **`MEGA`**
- **安卓**：应用商店搜 **`MEGA`**
- **注册**（邮箱即可，**不用卡**）

## 第 2 步：上传
```
① 打开 MEGA App
② 点右下角「+」
③ 选「上传文件」
④ 选你的录屏
```

## 第 3 步：生成分享链接
```
① 长按刚上传的文件
② 选「分享」/「Share」
③ 选「复制链接」/「Copy link」
   （可选：设置密码、有效期）
```

## 第 4 步：发我
**把链接（+ 密码）贴给我。**

## 我这边
```bash
megadl '你给的链接' --path user-uploads/
# 有密码：megadl --password 密码 '链接' --path user-uploads/
```

✅ **完成**
