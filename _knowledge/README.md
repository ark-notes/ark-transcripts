# 知识库（分类归档）

MasterD 不只做网站。所有需求、进度、成果按「域」分类归档。

## 目录

| 目录 | 域 | 内容 |
|---|---|---|
| （根） | **D0 通用** | `REQUIREMENTS.md` 角色准则、跨域规则 |
| `D1_网站/` | **D1 ARK 学习指南网站** | 需求、深挖成果、页面映射、进度 |
| `D2_Crypto/` | **D2 Crypto 咨询操作** | 行情查询、钱包、交易、策略偏好 |

| `D4_其他/` | **D4 其他业务** | 待分类的业务咨询 |

## 使用规则

1. **新需求进来 → 先判断属于哪个域 → 写进对应目录**
2. 不许散在对话里
3. 全部同步到 GitHub（`ark-transcripts/_knowledge/`）
4. 沙箱重启后 `restore.py` 自动拉回
