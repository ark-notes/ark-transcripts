# 项目体检清单（可查任何区块链项目）

> 用途：拿到一个项目，**10 分钟判断它安不安全**
> 方法：**不听宣传，只看链上**
> 更新：2026-10-01

---

# 第一层：基础信息核验（3 分钟）

| # | 查什么 | 怎么查 | 危险信号 |
|---|---|---|---|
| **1** | **合约地址** | 官网/白皮书/DexScreener 搜代币名 | 搜不到、或搜到多个同名 |
| **2** | **持币地址数** | BscScan → Holders | **< 1000** ← 危险 |
| **3** | **上线时间** | BscScan → 合约创建时间 | **刚上线几天** ← 危险 |
| **4** | **流动性规模** | DexScreener / AVE | **< 5 万美金** ← 危险 |
| **5** | **交易所收录** | CoinMarketCap / CoinGecko | **未收录** ← 谨慎 |

---

# 第二层：安全第一关 —— LP 底池（3 分钟）★

> **核心问题：底池锁了吗？锁了多少？**

| 检查项 | 怎么看 | 合格 | 危险 |
|---|---|---|---|
| **LP 是否上锁** | AVE → 点 LP → 看锁仓 | 已锁 | 未锁 → **随时撤池跑路** |
| **锁的类型** | 看是"时间锁"还是"黑洞锁" | **黑洞锁**（永久） | 时间锁 → 到期可取 |
| **锁仓比例** | 看百分比 | **≥ 95%** | **锁 20-50% → 没意义** |
| **剩余未锁部分** | 看地址 | 交易所地址（付手续费） | **项目方地址 ← 危险** |

### 【可以直接讲】
> 「**光锁了还不够，要看锁仓比例** —— 有的项目锁 20%、30%，**根本没有意义**。
> **必须接近 100% 全部上锁，而且最好是黑洞锁（永久）。**」

### 交叉验证（防第三方造假）
```
AVE 看到锁仓 → 去 BscScan 交叉验证
→ 打开 LP 合约 → Holders → 看是否黑洞地址（0x000...000 / 0xdead）
```

# 第三层：安全第二关 —— 铸币权限（2 分钟）★

> **核心问题：项目方能不能偷偷印币？**

| 检查项 | 怎么查 | 合格 | 危险 |
|---|---|---|---|
| **合约是否开源** | BscScan → 看有无绿标 Contract | 已开源 | 未开源 → **黑箱** |
| **铸币权限** | Read Contract → 找 `owner` / `minter` | **0x000...000（黑洞）** | 项目方地址 → **可无限增发** |
| **权限是否丢弃** | 看有没有 `renounceOwnership` 记录 | 已丢弃 | 未丢弃 |
| **有没有后门函数** | 看代币合约有没有 mint/burn 权限 | 无人类可控 | **有人可调用 → 危险** |

### 【可以直接讲】
> 「**铸币权限决定代币的生死命脉。**
> 如果项目方保留铸币权限：想拿底池的钱 → 敲代码铸币 → 砸到底池换钱；
> 不想玩了 → 增发十亿百亿 → **把底池全部掏空。**」

### ★ 进阶：查"隐藏条款"（分姐的方法）
```
BscScan → 合约代码 → 代码旁边的小三角符号 → 点开
→ 看有没有"隐藏条款"（如：最终解释权归项目方）
```
> **【可以直接讲】**：「**如果他真的是光明的，为什么不能直接写在明面上？为什么要藏到隐藏条款里？**」

# 第四层：安全第三关 —— 国库/资金（2 分钟）

> **核心问题：钱在谁手上？谁能动？**

| 检查项 | 怎么看 | 合格 | 危险 |
|---|---|---|---|
| **有没有国库** | 看白皮书/链上地址 | 有明确国库地址 | 没有 → 钱在项目方口袋 |
| **是否多签** | Gnosis Safe 查 | **多签（如 5/9）** | 单签 → 一个人能拿走 |
| **国库资金流向** | BscScan 查地址流水 | 公开可查 | **转进个人钱包 ← 危险** |
| **治理是否上链** | Tally / Snapshot | 有提案、有投票 | 无 → 一言堂 |

# 第五层：资金盘特征识别（对照检查）★

> 来源：9/26 夜聊 讲师分享

## 两种崩盘信号

| 信号 | 表现 |
|---|---|
| **① 赚够了** | 老板本打算赚 1 亿，结果突然进来 3 亿 → **想尽办法赶你走**（惯用手法：贼喊捉贼、黑客背锅） |
| **② 赚不够** | 底池涨到瓶颈，市场不景气 → **想尽办法搞活动刺激**（开大会 = 追悼会） |

## 怎么判断（链上数据说话）

### 【可以直接讲】
> 「如果一个项目**底池长期存在、没有增长，交易量也很小** → 说明**没有换手率**，**做不景气**。"
> "如果**底池不怎么变化、但交易量持续在变化** → 说明是**真正的换手率**。**」

## 资金盘 vs 真项目（对照表）

| 维度 | 资金盘 | 真项目 |
|---|---|---|
| **钱在哪** | 打给项目方账户 | 链上合约 |
| **能不能提** | 提现要"审核"，被驳回 | 随时可提 |
| **生态** | 没有 / 只有概念 | 有真实产品、能创收 |
| **权限** | 项目方可随时改规则 | 写死在合约里 |
| **治理** | 老板一言堂 | 社区投票 |

# 第六层：识别假"海外项目"（2 分钟）

> 来源：9/26 夜聊

| 检查项 | 怎么查 | 假的特征 |
|---|---|---|
| **创始人是真的人吗** | 谷歌/推特/YouTube 搜 | **只在会议现场出现，下台就找不到** |
| **团队有没有日常活动** | YouTube / Twitter | 没有日常更新 |
| **地址是不是中心化** | 链上查 | 钱能被打到个人账户 |

### 【可以直接讲】
> 「**真项目方你在会议现场才见得到，而且上台一定拿着稿子念 —— 你把稿子抽掉问他几个问题，他就露馅了。**"
> "**真正的海外组织，在 YouTube、推特上能看到他们日常正常工作。**」

# 第七层：输出风控结论

## 风险等级

| 等级 | 特征 |
|---|---|
| 🟢 **低风险** | LP 黑洞锁 ≥95% + 权限已丢弃 + 多签国库 + 有真实产品 |
| 🟡 **中风险** | 部分条件不满足（如时间锁、权限未丢弃但有说明） |
| 🔴 **高风险** | 未锁仓 / 权限可人为操作 / 国库单签 / 无生态 |

## 【可以直接讲】给客户的话
> 「**我不告诉你这个项目好不好 —— 我给你几个地址，你自己去查。**
> **链上数据不会骗人。**」
