# 深挖方法（用户确认 · 2026-10-01）

## 核心原则：**去重不丢信息**

> 用户原话：「重复的肯定是没有价值的，只需要找出重复里的不同之处就行。」

## 方法：主题归并 + 增量提取

### ❌ 错误做法
逐支产出 30 份文件 → 70% 内容重复 → 不是"精华"，是"重复笔记"

### ✅ 正确做法
```
1. 完整读每支（100%，分段）
2. 识别「主题」（如：治理提案 / 成交话术 / 收益计算）
3. 归并到对应主题文件
4. 重复内容：只记录「不同之处」（新角度、新数据、新案例）
5. 新内容：完整写入
```

## 增量提取示例

**同一个「20 号提案」，三位讲师的说法：**

| 讲师 | 说法 | 增量价值 |
|---|---|---|
| 大香蕉（9/26夜聊） | 「用机制代替人性，实现 (3,3)」 | 理论高度 |
| 文雄（9/25晨间） | 「涡轮前面设关卡，0.5 折」+ 老虎比喻 | **通俗解释 + 比喻** |

→ **归并时保留三种说法，而不是重复三遍"20号提案是什么"。**
