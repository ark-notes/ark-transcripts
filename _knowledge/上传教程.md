# 📱 手机上传教程（GitHub App）

## 一、装 App

**App Store / 应用商店搜：`GitHub`** → 装 → 登录你的 `ark-notes` 账号

---

## 二、传小文件（截图、文档 ≤25MB）

```
① 打开 GitHub App
② 进 ark-notes/ark-uploads
③ 进对应目录（screenshots / images / docs）
④ 点右上「...」→「Create new file」或「Upload files」
⑤ 选照片/文档 → 填个说明 → 提交（Commit）
```

⚠️ 有些版本 App 没有上传按钮 → **用手机浏览器打开 github.com**（步骤一样）

---

## 三、传大文件（视频 ≤2GB）★

```
① 手机浏览器打开：
   https://github.com/ark-notes/ark-uploads/releases/tag/videos

② 点右上角「✏️ Edit release」

③ 找到「Attach binaries by dropping them here or selecting them」
   → 点「selecting them」→ 选视频

④ 等上传完（大文件慢，用 WiFi）

⑤ 点底部「Update release」
```

---

## 四、传完告诉我

**说一句：**
- 「看上传」
- 「传好了」

**我会：**
1. 检查两个区（小文件 + 大文件）
2. 下载下来
3. 判断：有用的存正式库 / 临时的看完删
4. 告诉你结果

---

## 五、常见问题

| 问题 | 解 |
|---|---|
| **提示 "Add some files"** | 文件没选中（或太大），重新选 |
| **上传失败** | 检查网络；文件是否 >2GB |
| **找不到上传按钮** | 用手机浏览器（不是 App） |
| **传完我看不到** | 告诉我，我检查 |
