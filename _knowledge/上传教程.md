# 📤 怎么把录屏/截图传给我（最简单版）

> 目标：**1-2 分钟的录屏**，用 GitHub 传（免费，不用装东西）

---

# ⭐ 方法一：最简单（推荐）

## 第 1 步：打开这个链接

**手机浏览器或电脑浏览器都行：**

```
https://github.com/ark-notes/ark-uploads/upload/main/screenshots
```

## 第 2 步：把文件拖进去

**你会看到一个框，写着：**

```
Drag files here to add them to your repository
（或者：Choose your files）
```

**操作：**
- **手机** → 点「choose your files」→ 选录屏
- **电脑** → 直接拖进去

## 第 3 步：点最下面的绿色按钮

```
Commit changes
```

**完了。** 然后跟我说「看上传」。

---

# 如果上面的链接打不开

## 换成这个（备用路径）

```
① 打开：https://github.com/ark-notes/ark-uploads
② 点进 screenshots 文件夹
③ 点右上角「Add file」→「Upload files」
④ 选文件 → Commit changes
```

# ✅ 实测：**已经跑通了**

**你上传的 10MB 录屏 → 我成功下载。**

**所以：**

| 你的录屏 | 怎么办 |
|---|---|
| **≤25MB** | ✅ **传 screenshots 文件夹**（最简单） |
| **> 25MB** | 压缩到 720p，或用 Mega |

**建议：手机录屏设 720p，1-2 分钟 ≈ 10-25MB** ✅

# 方法二：大文件（≤2GB）用 Release

```
① 打开：
   https://github.com/ark-notes/ark-uploads/releases

② 找到「📤 上传录屏/视频（草稿区）」

③ 点进去 → 找到上传区域

④ 选文件 → 上传
```

---

# 方法三：超大文件用 Mega

**超过 2GB，或视频很多 → 用 Mega**

```
① 装 MEGA App（免费注册）
② 上传 → 分享 → 复制链接
③ 把链接发我
```

# 常见问题

| 问题 | 解决 |
|---|---|
| **提示 "Add some files"** | 文件没选中，重新选 |
| **上传卡住** | 换 WiFi；或文件太大 |
| **找不到按钮** | 用电脑试；或问 MasterD |
| **传完我看不到** | 告诉我，我检查 |
