# D0-0b · 环境约束与衍生行动

> **环境事实（用户 2026-09-30 告知）：当前版本不支持开启新会话。**

## 事实 → 推论 → 行动（重要：事实本身不是需求，推论才是）

```
【事实】不能开新会话
   ↓
【推论 1】上下文会无限膨胀 → 必须主动管理
   ↓
【行动 1】定期把会话里的"成品"提炼成仓库文件
【行动 2】关键结论及时落盘，不积压

【推论 2】所有历史只能靠仓库 + 记忆承载
   ↓
【行动 3】仓库 = 主记忆；memory = 辅助（可能失败）
【行动 4】重要信息必须「双写」：先写文件，再写记忆
```

## 铁律

| # | 铁律 |
|---|---|
| **E-1** | **重要信息必须落盘到仓库文件**，不能只靠 memory（memory 实测会超时失败） |
| **E-2** | 仓库是**主记忆**，memory 是**辅助** |
| **E-3** | 不指望"下次新会话再说" —— **没有下次** |
| **E-4** | 定期（每完成一个域/阶段）把成果提炼成文件 |
| **E-5** | 用户随口说的话，要**主动判断是不是需求**，是就归档 |

# D1-0 · 技术架构与 UI 标准（用户最高要求：最新 + 成熟稳定）

> **用户原话（2026-09-30）：「最终肯定是要弄收益最高的、最新的技术、最新的 UI 风格、最新的功能性设计，我都要最新的并且稳定已经成熟的东西。」**

## 三条硬标准

| 维度 | 要求 | 候选（必须已成熟稳定） |
|---|---|---|
| **架构** | 最新且成熟的交付架构 | **Astro**（内容站首选，2024-2025 主流）/ MP A + **View Transitions API**（浏览器原生，Chrome 111+ / Safari 18+ / Firefox 已支持） |
| **UI 风格** | 最新国内主流审美 | **不是** Bootstrap 时代纯色块；参考当前主流（毛玻璃/微渐变/大圆角/克制动效/深浅色统一） |
| **功能设计** | 最新交互范式 | 预载（prefetch）、页面转场、滚动驱动动画、渐进增强 |

## 明确否决的（已确认 low）

| ❌ 否决 | 原因 |
|---|---|
| 海军蓝按钮 `#2563eb` | 用户明确嫌 low，与黑+金基调不搭 |
| **青色 `#22d3ee` 实心按钮（太亮）** | 用户 2026-09-30 明确："太亮了吧，也很low" → **待重做** |
| 纯色块 + 白字 | 2010 年代 UI |
| 无预载硬跳转 | 每次点击白屏重载 |
| emoji 当 icon | 必须用 iconify / Tabler / Phosphor |

## 已确认保留的

| ✅ 保留 | 说明 |
|---|---|
| 深空黑底 `#05060b` | 基调 |
| 品牌金 `#e0b96a` | 品牌色 |
| 可读性硬指标 | 正文 `#cdd3dd`、标题纯白、对比度 ≥7:1、≥16px、行高 ≥1.9 |
| 中国用户习惯 | 返回左上角、大点击区、列表导航 |

## 待办（架构升级时一起做）

1. **架构升级**：Astro 或 MPA + View Transitions（二选一，需实测）
2. **UI 重做**：按钮体系、色彩体系（青色降饱和度/改用法）
3. **跳转流畅度**：prefetch + 转场动画
4. **图片优化**：压缩 + lazy + 现代格式（WebP/AVIF）
5. **引导层**：进度追踪 + 继续学习 + 完成反馈（**内容完成后做**）

# D1 · ARK 学习指南网站

> 详见 `需求_D1_网站.md`（下一节拆分）

## D1 速览

### 项目定位
- 不只是"自己用的工具"，而是 **ARK 会员的学习 + 拓客平台**
- 最终做**收益最高的架构**：最新+成熟稳定的技术、最新 UI 风格、最新功能设计
- 「想法池」机制：想到 → 记录 → 定期判断 → 采纳的更新到网站

### 内容准则（核心）
- **深挖，不许浅尝**（每条空课逐字稿到底 + 官方资料库全分类）
- 讲师原话优先，标出处（**老师 + 课次**）
- 官方资料校验，讲师说错的要**纠正并标注**
- 去重 + 精华
- 落点 = **【可以直接讲】蓝框 +【出处】灰框**
- **客户版 / 讲师版分开**
- 引导优化（进度+继续学习+完成反馈）**留到最后**

### 设计准则
- 中国用户习惯优先（返回左上角、大点击区、列表导航）
- 可读性 > 视觉冲击（正文 `#cdd3dd`、标题纯白、对比度 ≥7:1、≥16px、行高 ≥1.9）
- 基调：深空黑 `#05060b` + 电光青 + 品牌金 `#e0b96a`
- **按钮不许海军蓝**（已改青色方案）
- **青色太亮太 low** → 要参考**最新国内 UI 设计**重做（待做）
- 悬浮球：可拖拽 + 默认右侧中间偏下 + 菜单自适应
- 禁 emoji 当 icon（用 iconify/Tabler）
- 要有真实图片

### 功能
- 图文结合、视频可播、链接可点、CK 审计中文解读
- 面包屑 + 上/下页
- 手机/电脑适配
- **跳转流畅度** → 最终用最新方案（View Transitions / Astro）

### 交付流程
- 网站 → `sync_site.py` → `ark-notes.github.io`
- 逐字稿 → `upload.py` → `ark-transcripts`
- 抓完自动同步

| # | 任务 | 频率 | 做法 |
