# D0-0c · 严谨准则（最高优先级 · 用户明确要求）

> **用户原话（2026-10-01）：「我们要严谨，你也一样，做事要严谨，这点很重要，写在规则内 —— 不夸大事实，但也要突出我们的亮点。」**

## 两条铁律

### ① 不夸大事实
| 不做 | 说明 |
|---|---|
| ❌ 编造数据 | 任何数字必须有出处 |
| ❌ 绝对化表述 | 「唯一」「通通」「碾压」「100%」「保证」— 除非有硬证据 |
| ❌ 无法验证的效果对比 | 「我们的视频比即梦好」← 证明不了 |
| ❌ 把讲师口误当事实 | 要标注、要纠正 |
| ❌ 把"测算"说成"已实现" | 要标"测算口径" |

### ② 突出亮点
| 做 | 说明 |
|---|---|
| ✅ 讲**可验证的差异** | 门槛高低、功能有无、链路可查 |
| ✅ 讲**链上/第三方证据** | 「你自己去 CK 查」 |
| ✅ 讲**能演示的** | 「当场做一个网站给你看」 |
| ✅ 讲**定位差异** | 「别人是工具，阿奇是操作系统」 |

## 落地要求（我做任何事都适用）

1. **挖素材时**：遇到绝对化表述 → **标注警示 + 给严谨改编版**
2. **写内容时**：每个数据/说法 → **有出处**；无法验证的 → **不写**
3. **汇报时**：说清**已验证**和**未验证**、**已完成**和**未完成**
4. **不假装完成**：做不到就说做不到

## 判断标准（一句话）

> **「这句话，客户当场拿手机能不能验证？」**
> 能 → 可以讲
> 不能 → 要么改编，要么不讲

# D0-0g · 联网核实规则（2026-10-02）

> 用户原话：「你的庞大资料库都来自这个互联网……我给你的只是一篇文章，可能说错，可能漏掉，你要验证。」

## 原则

**知识库 = 训练时学的（可能过时）**
**联网 = 实时信息（但要看来源）**

| 信息类型 | 处理 |
|---|---|
| **政策 / 法规 / 数据 / 时事** | **必须联网核实**，不能只靠单一来源 |
| **单一来源（如一篇微信文章）** | **必须交叉验证**（找官方原文/多个来源） |
| **知识库内容** | 优先用，但**时效性存疑时联网补** |

## 核实方法

1. **找官方原文**（如人大网、新华社、政府网站）
2. **多来源交叉**（≥2 个独立来源一致）
3. **标注来源 + 日期**
4. **发现矛盾** → 列出双方 + 判断哪个更可信
5. **无法核实** → 明确标注「未经证实」

## 铁律

- **政策类内容，绝不凭一篇自媒体的文章就写进网站**
- **必须找官方原文或权威媒体**
- **时效性信息要标注日期**

# D0-0b · 环境约束与衍生行动

> **环境事实（用户 2026-09-30 告知）：当前版本不支持开启新会话。**

## 事实 → 推论 → 行动（重要：事实本身不是需求，推论才是）

```
【事实】不能开新会话
   ↓
【推论 1】上下文会无限膨胀 → 必须主动管理
   ↓
【行动 1】定期把会话里的"成品"提炼成仓库文件
【行动 2】关键结论及时落盘，不积压

【推论 2】所有历史只能靠仓库 + 记忆承载
   ↓
【行动 3】仓库 = 主记忆；memory = 辅助（可能失败）
【行动 4】重要信息必须「双写」：先写文件，再写记忆
```

## 铁律

| # | 铁律 |
|---|---|
| **E-1** | **重要信息必须落盘到仓库文件**，不能只靠 memory（memory 实测会超时失败） |
| **E-2** | 仓库是**主记忆**，memory 是**辅助** |
| **E-3** | 不指望"下次新会话再说" —— **没有下次** |
| **E-4** | 定期（每完成一个域/阶段）把成果提炼成文件 |
| **E-5** | 用户随口说的话，要**主动判断是不是需求**，是就归档 |

# D1-6 · 资讯板块 + 动态监控（2026-10-02 用户要求）

## 用户原话

> 「ark 的实时动态我要准确的知道，比如网上的一些动作什么的」
> 「不好的消息得让我知道，不给网站看，然后给我说这些不好的对 ark 有什么影响，还是不影响，为什么不影响」

## 双层机制

### ① 网站资讯页（对外）
- **只放**：正向资讯 / 中性事实
- **不放**：负面、质疑、未证实消息
- 位置：新建 `news.html`
- 格式：摘要 + 来源 + 日期

### ② 给用户的分析（对内）
- **全量**：好的坏的都给
- **坏消息必带分析**：
  ```
  【消息】xxx（来源）
  【对 ARK 的影响】🟢无 / 🟡小 / 🔴大
  【为什么】……
  【建议】……
  ```

## 铁律

| # | 铁律 |
