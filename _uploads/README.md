# 📤 上传区（用户专用）

把要给我的文件拖到这里就行。**只有你能看到（仓库私有/受限）。**

## 目录

| 目录 | 放什么 |
|---|---|
| `screenshots/` | bug 截图、界面截图 |
| `docs/` | 文档、PDF、word |
| `videos/` | 视频（注意 GitHub 单文件 ≤100MB） |
| `images/` | 图片素材（一图读懂、二维码等） |

## 用法

1. 打开这个仓库
2. 进对应目录
3. 点「Add file」→「Upload files」
4. 拖进去 → 提交

## MasterD 会怎么处理

- **有用的**（素材/文档）→ 存进正式库，用进网站
- **临时的**（bug 截图）→ 我看完就删
- 处理完我会告诉你
